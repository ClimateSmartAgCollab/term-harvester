# Darwin Core Simple Record v2023-09-14 — Field Hierarchy
# Source: https://dwc.tdwg.org/xml/tdwg_dwc_simple.xsd (version 2023-09-14)
# Term definitions: https://dwc.tdwg.org/list/
#
# Columns (tab-separated):
#   1. category             — section name (repeated on every row in that section)
#   2. field_name           — verbatim Darwin Core term name (namespace prefix for non-dwc: terms)
#   3. slot_name            — slot key: snake_case version of the DWC field name
#   4. data_type            — string | integer | decimal | date | datetime | time | boolean | uri | enumeration
#   5. enumerations         — recommended enum key(s), comma-separated; '-' for none
#   6. description          — DWC definition
#   7. comments             — additional notes, recommendations, and examples
#
# Section header rows: field_name is empty; data_type is '-'; col 6 holds section description; col 7 is empty.
# Enumerations defined in this module: DCMIType, DwCBasisOfRecord, DwCSex, DwCLifeStage, DwCVitality,

#   DwCMaterialEntityType, DwCDisposition, DwCGeoreferenceVerificationStatus,
#   DwCTaxonRank, DwCNomenclaturalCode, DwCTaxonomicStatus

Record-Level Terms			-	-	General metadata about the record and dataset; applies to all DWC record types	-
Record-Level Terms	dc:type	type	enumeration	DCMIType	The nature or genre of the resource	Must be populated with a value from the DCMI type vocabulary (https://www.dublincore.org/specifications/dublin-core/dcmi-type-vocabulary/2010-10-11/).
Record-Level Terms	dcterms:modified	modified	datetime	-	The most recent date-time on which the resource was changed (ISO 8601)	Recommended best practice is to use a date that conforms to ISO 8601-1:2019.
Record-Level Terms	dc:language	language	string	-	The language of the resource (BCP 47 tag, e.g. 'en', 'fr')	Recommended best practice is to use a controlled vocabulary such as RFC 5646. This term has an equivalent in the dcterms: namespace that allows only an IRI as a value, whereas this term allows for any string literal value.
Record-Level Terms	dcterms:license	license	uri	-	Legal document giving official permission to do anything with the resource (URI)	-
Record-Level Terms	dcterms:rightsHolder	rights_holder	string	-	Person or organization owning or managing rights over the resource	-
Record-Level Terms	dcterms:accessRights	access_rights	string	-	Information about who can access the resource or its security status	Access Rights may include information regarding access or restrictions based on privacy, security, or other policies.
Record-Level Terms	dcterms:bibliographicCitation	bibliographic_citation	string	-	Bibliographic reference for the resource as a statement indicating how it should be cited	From Dublin Core, "Recommended practice is to include sufficient bibliographic detail to identify the resource as unambiguously as possible." The intended usage of this term in Darwin Core is to provide the preferred way to cite the resource itself - "how to cite this record". Note that the intended usage of dcterms:references in Darwin Core, by contrast, is to point to the definitive source representation of the resource - "where to find the as-close-to-original reference", if one is available.
Record-Level Terms	dcterms:references	references	uri	-	A related resource referenced, cited, or otherwise pointed to by the described resource (URI)	From Dublin Core, "This property is intended to be used with non-literal values. This property is an inverse property of Is Referenced By." The intended usage of this term in Darwin Core is to point to the definitive source representation of the resource (e.g., dwc:Taxon, dwc:Occurrence, dwc:Event), if one is available. Note that the intended usage of dcterms:bibliographicCitation in Darwin Core, by contrast, is to provide the preferred way to cite the resource itself.
